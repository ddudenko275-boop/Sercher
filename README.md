# Sercher — монитор цен на Авито

Ищет на Авито объявления, подходящие под условия, которых **нет в фильтрах Авито**,
и шлёт ссылки в Telegram. Текущая задача: **золотые украшения 585 пробы дешевле
6700 ₽ за грамм**, доставка/самовывоз в Ростов-на-Дону, из не слишком далёких
регионов.

Ключевая ценность — фильтр **«цена за грамм»**: Авито умеет фильтровать только по
полной цене, а вес лежит в тексте объявления. Мы достаём вес и делим цену на него.

## Как работает

```
выдача Авито ──▶ дедуп (SQLite) ──▶ фильтр (585 + ₽/г + регион)
                                         │ веса нет в заголовке?
                                         ▼
                                  открыть объявление → вес/регион
                                         │ подходит?
                                         ▼
                                   Telegram-уведомление
```

Один проход за запуск; интервал (7–10 мин) задаёт Планировщик задач Windows.

## Структура

```
src/pricewatch/
├── config.py     # что ищем, порог ₽/г, регионы, профиль браузера, Telegram
├── collector.py  # Playwright: выдача + страница объявления (обход антибота)
├── extract.py    # вес и проба 585 из текста (регулярки)
├── filter.py     # решение «подходит / нет» + причина
├── store.py      # SQLite: дедуп и снижение цены
├── notify.py     # отправка в Telegram (HTTP, без библиотек)
├── runner.py     # один проход: связывает всё воедино
└── demo.py       # офлайн-проверка ядра-фильтра (без Авито и API)
```

## Установка

```bash
pip install -r requirements.txt
python -m playwright install chromium   # плюс нужен установленный Google Chrome
```

## Настройка

- Условия поиска и порог — в [`src/pricewatch/config.py`](src/pricewatch/config.py).
- Telegram — через переменные окружения (`.env`), не в коде:
  ```
  TELEGRAM_BOT_TOKEN=...   # от @BotFather
  TELEGRAM_CHAT_ID=...     # свой id (@userinfobot)
  ```
  Без них монитор работает в режиме dry-run (печатает уведомления в консоль).

## Запуск

```bash
python -m pricewatch.demo   # офлайн-проверка логики фильтра
python -m pricewatch        # один проход монитора (ходит на Авито)
```

## Обход антибота Авито (важно)

Рабочая формула (проверена): **настоящий Chrome** (`channel="chrome"`, не встроенный
Chromium) + **отдельный прогретый профиль** с cookies + **без блокировки ресурсов** +
спокойный темп. Профиль — `data/chrome-profile` (в `.gitignore`), не основной профиль
пользователя: так не банится, не пачкает личный Chrome и не рискует аккаунтом
(страницы объявлений видны без входа).
